# 변경 이력

각 항목은 배포 모달의 release notes에 **그대로 붙여넣는** 원문이다.
새 버전은 위에 쌓는다.

---

## 2026-09-23 — 옛 BDL 이름 인식

```
• 옛 BDL 스타일 이름을 인식합니다. font/gray20% · stroke/gray90% 처럼 지금과 이름
  체계가 다른 옛 라이브러리를 쓰던 화면도 이제 대상이 잡힙니다.
• 접두어(Light/ · Dark/)가 없는 옛 이름도 표에 있으면 인식합니다.
• 이름과 실제 쓰임이 어긋나는 회색(bg/ 인데 선으로 쓰이는 등)은 레이어 맥락을 보고
  면이면 면 토큰, 선이면 선 토큰을 제안합니다.
```

## 2026-09-22 — 첫 버전

```
• 선택한 프레임 안의 레거시 컬러를 MDS 3.0 Foundation 변수로 바꿉니다.
  Better Design Library 스타일, MDS Master 변수, 원시 컬러, hex를 모두 찾습니다.
• Check designs처럼 항목마다 바뀔 토큰을 보여 주고, 드롭다운에서 다른 토큰을 고를 수 있습니다.
• 원시 컬러와 hex는 레이어 맥락(글자·아이콘·배지·구분선·테두리·딤·면)을 읽어 시맨틱을 제안합니다.
• BDL Dark/ 스타일이나 Master 다크 모드를 쓰던 프레임은 Foundation 다크 모드로 지정합니다.
• 항목을 누르면 해당 레이어를 선택합니다. 적용은 한 번의 실행 취소로 되돌릴 수 있습니다.
```
